# AnyFight: Dream Battles

AI-powered iOS/Android fighting game built with Expo.

Pick any two characters, generate AI fighter profiles, watch them battle, and get a Joe Rogan-style play-by-play recap.

## Stack
- Expo SDK 54 (React Native)
- Express API server
- OpenAI GPT-5.4 for fighter profiles, matchup analysis, narration & recap
- expo-audio for TTS commentary
- pnpm monorepo
